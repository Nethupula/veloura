# Veloura

Veloura is a full-stack e-commerce website for selling
jewelry products online.

## Brand

**Veloura — Made to Make You Shine**

## Technology

- HTML5
- CSS3
- Bootstrap
- JavaScript
- PHP
- MySQL
- Apache

## Main Features

- Product browsing
- Categories
- Search and filtering
- Shopping cart
- Wishlist
- Customer accounts
- Checkout
- Cash on Delivery
- Online payments
- Coupons
- Inventory management
- Order management
- Admin dashboard
- Email notifications
- WhatsApp integration
- SEO and security
